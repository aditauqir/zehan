Zirn install note
=================

This Zirn build may not be notarized by Apple yet. macOS may warn that it
cannot verify the app is free of malware the first time you open it.

Install
-------

1. Drag Zirn.app into Applications.
2. Open Applications in Finder.
3. Control-click or right-click Zirn, then choose Open.
4. In the warning dialog, choose Open again.

If macOS does not show the Open button:

1. Try opening Zirn once from Applications.
2. Open System Settings > Privacy & Security.
3. Find the Zirn warning near the bottom of the page.
4. Choose Open Anyway, then confirm Open.

Only use Zirn installers downloaded from the official GitHub release page:

https://github.com/aditauqir/zehan/releases/latest

After Zirn opens once, future launches should work normally.
